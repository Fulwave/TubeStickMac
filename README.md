# TubeStickMac

Watch free over-the-air digital TV (ATSC) on a modern Mac with an **equinux TubeStick Hybrid ATSC** (USB `1d2c:1012`), using VLC as the player. This is an independent, open-source driver and app. It works on current macOS (Apple silicon and Intel) with no kernel extension and no vendor software.

> Not affiliated with, authorized by, or endorsed by equinux AG. "equinux" and "TubeStick" are trademarks of their owners and are used here only to name the hardware this software works with. The vendor's software and servers are discontinued; nothing from them is included in this repository.

## Status

Works on the author's stick (macOS 26, Apple silicon): tuning, channel scanning, station names, live viewing in VLC, in-place channel switching. This is early software for one USB device. See [Known limits](#known-limits).

## Quick start

Requirements: macOS 12 or later, [VLC](https://www.videolan.org), the Xcode command line tools (`xcode-select --install`), an antenna.

```bash
git clone https://github.com/Fulwave/TubeStickMac.git
cd TubeStickMac
swift build -c release

.build/release/tubestick firmware      # once: downloads the tuner firmware (12 KB)
.build/release/tubestick scan          # finds stations, about 2 minutes
.build/release/tubestick list
.build/release/tubestick watch 7.1     # opens VLC; Ctrl-C stops
```

Plug the stick straight into the Mac, or into a powered hub. Quit any other program that uses the stick first.

### Menu bar app

```bash
scripts/make-app.sh
open build/TubeStick.app
```

The app has a Dock icon and a menu bar icon (a TV on a blue square); the window's display-mode picker can hide either one. The app icon is `Resources/AppIcon.icns`, generated by `scripts/make-icon.swift`. Choose **Scan for Stations** once, then pick a station to watch it in VLC. Quitting the app stops the stream cleanly. The app is unsigned (ad-hoc), so macOS may ask you to allow it in System Settings > Privacy & Security the first time.

### Command line

| Command | What it does |
| --- | --- |
| `tubestick firmware` | Download and verify the tuner firmware |
| `tubestick scan [--all] [--channels 3,27]` | Scan RF channels 2-36 (2-51 with `--all`) and save the station list |
| `tubestick list` | Show saved stations with signal quality |
| `tubestick watch <station>` | Tune, stream and open VLC. `<station>` is `7.1`, part of a name, or `rf27` for a whole RF channel |
| `tubestick record <station> <seconds> <file.ts>` | Record to a transport stream file |
| `tubestick analyze <file.ts>` | List stations and damage in a captured stream (no stick needed) |
| `tubestick reset` | Software unplug and replug |

## The firmware file

The stick's tuner (Xceive XC5000) needs a small firmware file loaded every time it is plugged in. That file is **not part of this repository**. `tubestick firmware` downloads the public `dvb-fe-xc5000-1.6.114.fw` from the [linux-firmware](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git) project (redistributable under Xceive's license) and checks its SHA-256. You can also point `TUBESTICK_FIRMWARE` at your own copy.

## How it works

- `Sources/CTubeStick`: talks to the Empia EM2883 bridge over IOKit (registers and I2C to the tuner and the LG LGDT3304 demodulator) and reads the isochronous stream with IOUSBHost. Also parses MPEG-TS and ATSC PSIP (station names) and can reduce a multi-program stream to one program.
- `Sources/TubeStickKit`: Swift API (scanning, saved station list, UDP relay to VLC).
- `Sources/tubestick`, `Sources/TubeStickMenu`: the command line tool and the menu bar app.
- `docs/findings.md`: how the hardware protocol was worked out, in order, including dead ends. Start here if you want to add another device.
- `tools/`: the original research probes (C), kept because they are handy for debugging.

Video goes from the stick to a UDP port on `127.0.0.1` and VLC plays `udp://@127.0.0.1:1234`.

## Known limits

- Only the **Hybrid ATSC** (`1d2c:1012`) is supported, and only over-the-air 8VSB (US/Canada). Cable (QAM), analog and the other TubeStick models are not.
- The hardware can wedge. We found the stick hangs if tuner firmware is loaded into a tuner that already has it (the tools prevent this) and if a stream is left running with nobody reading. If it stops answering, unplug it and plug it back in.
- No program guide, no DVR scheduling, no signed or notarized builds yet.
- Reception depends on your antenna. `tubestick list` shows a quality grade per station.
