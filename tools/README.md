# Research probes

Small C programs used to work out the hardware protocol (see `../docs/findings.md`). They are not needed to use the app; the supported code is in `Sources/`. Build commands are at the top of each file or in the `build_*.sh` scripts (outputs go to the ignored `dist/` and `build/` folders). `live.sh` is the original shell-script way to watch a channel in VLC.
